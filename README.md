# G R A M And Associates LLP - Review & Feedback System

A streamlined, modern review and feedback redirection system for **G R A M And Associates LLP (Chartered Accountants)**.

## Features
- **Smart Feedback Redirection**:
  - **4 & 5 Stars**: Review text is copied to the user's clipboard and redirected directly to the Google Review page.
  - **1 & 2 Stars**: Users are redirected to WhatsApp (`+91 8290911347`) for private resolution of complaints.
- **Custom Prompts for CA Firm**: Tailored suggested prompts covering ITR, GST, Audit, Tax Planning, and Corporate Compliances.
- **Interactive UI**:
  - Welcome animation powered by GSAP.
  - 5-Star Confetti celebrations.
  - Fully editable review textarea with carousel navigation.
- **Mobile Responsive**: Built with an elegant dark theme, optimized for mobile screens.
